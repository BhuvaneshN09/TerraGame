# Development log

## Current state

FALLSHIP is a browser game built with native Canvas, ES modules, Vite, and Playwright. The current playable slice has five connected ship maps, trying to make them separate shapes. six repair machines per level, Morrow’s briefing (Jus a lil alien that assissts you), a centered T-map, timed runs, collision, camera tracking, menus, and a small static Python checker. The bundled VT323 face is used for the canvas labels and DOM UI.
